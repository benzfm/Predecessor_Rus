# Русская локализация Predecessor

Неофициальный литературный перевод Predecessor (Omeda Studios) на русский язык. Это любительский проект, разработчики игры его не поддерживают и не одобряли.

Переведены:
- интерфейс и описания способностей всех героев;
- перки, предметы и их эффекты;
- облики и Вечные;
- задания и магазин;
- подсказки и настройки.


**Версия игры: v1.18.2** обновление от 24.11.2026.

## Установка

1. Скачайте `Game.locres` со страницы [Releases](../../releases) (последний релиз).
2. Откройте папку игры. В Steam: ПКМ по Predecessor → «Управление» → «Просмотреть локальные файлы».
3. Положите файл по пути:
   ```
   Predecessor\Content\Localization\Game\ru-RU\Game.locres
   ```
   Если папки `ru-RU` нет, создайте её. Имя файла должно быть ровно `Game.locres`.
4. В настройках игры выберите язык **Русский**.

Чтобы удалить перевод, удалите файл `Game.locres` из папки `ru-RU`.

После крупных обновлений игры часть новых строк может отображаться на английском, пока не выйдет свежая версия перевода. Если английский оригинал строки изменился, игра автоматически показывает его вместо устаревшего перевода, поэтому файл ничего не ломает.

## Нашли ошибку? Есть предложение или пожелание по части формулировок?

Создайте [Issue](../../issues). Укажите, где в игре встречается строка, и приложите скриншот, если есть возможность. Предложения по терминам тоже принимаются.
